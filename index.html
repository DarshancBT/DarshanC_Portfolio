DC Motor Speed Controller - KiCad Project

Designed and developed a DC motor speed controller PCB using the NE555 timer IC and TIP122 transistor for PWM-based motor speed regulation. The project includes a custom schematic, PCB layout, and 3D model created in KiCad with optimized routing and component placement. The circuit provides adjustable motor speed control through a potentiometer while ensuring stable operation, compact design, and efficient power handling for embedded and electronics applications.

KiCad PCB Design NE555 Timer PWM Control Motor Driver TIP122 Power Electronics Circuit Design

USB to UART Converter - KiCad Project

Designed a compact USB to UART converter PCB using KiCad based on the CP2102 USB-to-Serial IC. The project includes a USB Type-C interface, ESD protection, status LEDs, external UART header pins, and optimized PCB routing for reliable serial communication. The board was developed with a fully custom schematic, PCB layout, and 3D visualization to ensure compact size, manufacturability, and efficient signal integrity for embedded system debugging and programming applications.

KiCad PCB Design USB Type-C CP2102 UART Communication Schematic Design Embedded Hardware
